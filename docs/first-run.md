# 述播被控端 · 首次打开指引

被控端未做公证（macOS 侧已用自签代码签名证书签名，用于让系统授权跨版本保留；Windows 侧未签名），因此**每次安装新版本**首次打开时系统都会弹出安全提示，属正常现象，按以下步骤放行即可（同一版本只需一次）。

---

## Windows：SmartScreen 提示

首次双击 `ScriptCueAgent.exe` 时，可能出现蓝色窗口"Windows 已保护你的电脑"：

1. 点击窗口中的 **"更多信息"** 文字（在提示文字下方，字体较小）；
2. 点击出现的 **"仍要运行"** 按钮；
3. 程序正常启动，以后再打开不会再提示。

> 若公司/个人电脑装有安全软件并拦截了程序，请将 `ScriptCueAgent.exe` 加入信任/白名单。

---

## macOS：安装与首次打开

### 安装（挂载 .dmg）

1. 双击下载的 `ScriptCueAgent-macos-<架构>.dmg` 挂载磁盘映像；
2. 在弹出窗口中将 **ScriptCue** 图标拖到右侧 **Applications** 快捷方式，即完成安装；
3. 安装完成后可在启动台或"应用程序"文件夹找到述播（Apple Silicon 用 arm64 包，Intel 芯片用 x86_64 包）。

### 首次打开 / 每次升级后首次打开（Gatekeeper 提示）

应用已用自签证书签名但**未做公证**，每次下载安装新版本时系统都会提示
"无法验证开发者"，按以下步骤放行：

1. 双击 `ScriptCue.app`，在弹出的提示中点击"完成"（不要移入废纸篓）；
2. 前往 **系统设置 → 隐私与安全性**，页面下方会出现"已阻止使用 ScriptCue"，点击 **"仍要打开"**；
3. 输入开机密码确认，程序启动。

> 旧版指引中的"右键 → 打开"在较新的 macOS 上已不可用，请统一走上面的放行流程。

### 授予辅助功能权限（必须）

述播需要模拟按键，首次运行会自动向系统发起正式申请：

1. 系统弹出"ScriptCue 想要控制你的电脑"申请框，点击 **"打开系统设置"**
   （程序已自动把 ScriptCue 登记进辅助功能列表，无需手动"+"添加）；
2. 在 **隐私与安全性 → 辅助功能** 列表中，打开 **ScriptCue** 右侧开关；
3. 回到述播弹窗点击 **"重试"**，自检通过即可使用。

### 升级安装后仍提示需要授权？

系统按"代码身份"（签名）记录辅助功能授权。从旧版本升级后，若辅助功能列表里
已有一条显示"已打开"的 ScriptCue 却仍弹授权提示，说明那条记录属于旧版本。
程序会自动清除旧记录并重新登记，按弹窗提示重试一次即可；此后**同一签名身份
的所有版本都不再需要重新授权**。

> 注意：macOS 系统大版本更新后，辅助功能权限可能被重置。若启动时自检失败告警，按上面步骤重新授权即可。

---

## 应用内更新（v1.1.0 起）

述播被控端会**自动检查并下载**新版本，但**替换与重启需要你点一下**（避免影响演出中）：

1. 程序启动约 15 秒后自动检查，之后每 6 小时检查一次（也可点状态区的「检查更新」按钮）；
2. 发现新版本后自动下载（演出中会等空闲后再下载），完成后状态区会显示：
   **发现新版本 vX.Y.Z（已下载，点击更新）**——点击这行文字即可更新；
3. 弹出确认框后点「是」，程序会自检新版本、替换并自动重启；重启后重新加入房间即可。

**升级不会再弹安全提示**：

- macOS：新版本由程序自身下载安装，不经过浏览器，系统不会判定为“下载的应用”，
  **不再需要“仍要打开”放行**；配合自签证书签名，辅助功能授权也能跨版本保留；
- Windows：新版本由程序自身落盘，不携带“来自互联网”标记，**重启后不会再弹 SmartScreen**。

**想回到上一版本？** 更新后状态区的「回退上一版本」按钮可用（仅保留最近一次升级前的版本），
点击确认后程序自动换回并重启。若新版本启动后连续两次异常退出（崩溃/被强制结束），
程序也会自动回退上一版本；正常关闭程序不会触发自动回退。

**更新失败怎么办？** 程序会保留现有版本不受影响，日志区会给出提示；可再点一次「检查更新」
重试，或到 GitHub Release 手动下载对应平台的新版本包手动安装（首次安装方式同上方各节）。

## 常见问题

| 现象 | 处理 |
|---|---|
| 启动时"按键自检失败" | Windows：检查安全软件拦截；macOS：未完成辅助功能授权 |
| 一直显示"连接中…" | 核对服务器地址是否正确（含端口）；检查本机网络 |
| 提示"房间口令错误" | 与导控核对房间码与口令（房间码为 6 位，不区分大小写） |
| 触发后播放器没反应 | 确认播放器窗口在前台且处于焦点；演出前务必用主控端"单设备测试触发"验证 |

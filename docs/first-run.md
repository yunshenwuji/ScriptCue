# 述播被控端 · 首次打开指引

被控端目前**未做数字签名**（签名/公证流程暂缓），首次打开时系统会弹出安全提示，属正常现象，按以下步骤操作一次即可，之后不再出现。

---

## Windows：SmartScreen 提示

首次双击 `ScriptCueAgent.exe` 时，可能出现蓝色窗口"Windows 已保护你的电脑"：

1. 点击窗口中的 **"更多信息"** 文字（在提示文字下方，字体较小）；
2. 点击出现的 **"仍要运行"** 按钮；
3. 程序正常启动，以后再打开不会再提示。

> 若公司/个人电脑装有安全软件并拦截了程序，请将 `ScriptCueAgent.exe` 加入信任/白名单。

---

## macOS：安装与首次打开

### 安装（挂载 .dmg）

1. 双击下载的 `ScriptCueAgent-macos-<架构>.dmg` 挂载磁盘映像；
2. 在弹出窗口中将 **ScriptCue** 图标拖到右侧 **Applications** 快捷方式，即完成安装；
3. 安装完成后可在启动台或"应用程序"文件夹找到述播（Apple Silicon 用 arm64 包，Intel 芯片用 x86_64 包）。

### 首次打开（Gatekeeper 提示）

首次双击 `ScriptCue.app` 时，可能提示"无法打开，因为来自身份不明开发者"或"已损坏"：

### 方法（一次即可）

1. 在访达（Finder）中找到 `ScriptCue.app`；
2. **按住 Control 键点击**（或右键点击）图标，在弹出菜单中选择 **"打开"**；
3. 在弹出的确认窗口中再次点击 **"打开"**；
4. 程序启动后按提示授予"辅助功能"权限（见下）。

> macOS Ventura（13）及以上版本：若右键打开仍被阻止，前往
> **系统设置 → 隐私与安全性**，页面下方会出现"已阻止 ScriptCue"，点击 **"仍要打开"**。

### 授予辅助功能权限（必须）

述播需要模拟按键，首次运行会自动引导：

1. 程序弹出权限提示时点击 **"重试"**，会自动打开系统设置的对应页面；
2. 在 **隐私与安全性 → 辅助功能** 列表中，找到 **ScriptCue**（若不在列表，点击 "+" 从应用程序中添加）；
3. 打开其右侧开关；
4. 按系统提示**重新启动**述播被控端；
5. 再次打开程序，自检通过即可使用。

> 注意：macOS 系统大版本更新后，辅助功能权限可能被重置。若启动时自检失败告警，按上面步骤重新授权即可。

## 常见问题

| 现象 | 处理 |
|---|---|
| 启动时"按键自检失败" | Windows：检查安全软件拦截；macOS：未完成辅助功能授权 |
| 一直显示"连接中…" | 核对服务器地址是否正确（含端口）；检查本机网络 |
| 提示"房间口令错误" | 与导控核对房间码与口令（房间码为 6 位，不区分大小写） |
| 触发后播放器没反应 | 确认播放器窗口在前台且处于焦点；演出前务必用主控端"单设备测试触发"验证 |

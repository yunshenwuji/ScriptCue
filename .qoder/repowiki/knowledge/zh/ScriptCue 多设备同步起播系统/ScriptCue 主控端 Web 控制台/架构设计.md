单页应用，由 index.html 提供首页（创建/加入房间）与房间控制台两个视图，app.js 作为唯一逻辑入口，style.css 负责样式。运行时以全局 state 对象集中管理 WebSocket 连接、token、房间信息、agent Map 与当前活动指令；connect() 建立 ws://或 wss:// 到 /ws 的连接，onmessage 经 dispatch() 按 msg.type 分派到 controller.joined / agent.updated / command.scheduled / command.cancelled / command.receipt / error 等分支。UI 通过 $() 辅助函数直接操作 DOM，renderAgents()/renderReceipts()/showCountdownBanner() 等函数在状态变更后刷新视图。指令生命周期：sendCommand() 发送 controller.command → 收到 command.scheduled 后启动 requestAnimationFrame 倒计时 → 到期后等待 RECEIPT_TIMEOUT_MS 毫秒汇总回执并渲染。重连采用指数退避（上限 RECONNECT_MAX_S=10s），长按触发通过 attachHold() 实现 HOLD_MS=1000ms 防误触。协议版本 PROTO=1 硬编码，所有消息结构遵循 docs/protocol.md。

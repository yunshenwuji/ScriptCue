- 全局 state 对象集中持有连接、会话、agent 集合与活动指令等运行时数据，所有 UI 更新从该状态派生。
- DOM 访问统一通过 $() 封装 document.getElementById，避免散落的全局变量引用。
- WebSocket 消息处理集中在 dispatch() 中按 msg.type 进行 switch 分派，新增消息类型需在此扩展。
- 用户危险操作（全体起播、全体测试）通过 attachHold() 实现长按 HOLD_MS=1000ms 确认，防止误触。
- 时间计算统一使用 serverNow() = Date.now() + state.serverOffset 对齐服务器时间，而非直接使用本地时钟。
- 常量（PROTO、HOLD_MS、RECEIPT_TIMEOUT_MS、DELTA_WARN_MS、RECONNECT_MAX_S）集中在文件顶部集中声明，便于调整策略参数。

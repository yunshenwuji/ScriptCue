仓库以 server/controller/agent 三个独立子模块构成星型拓扑：server（FastAPI + WebSocket）作为中心节点提供房间管理、指令广播与审计日志；controller 是浏览器端主控页面，由 server 静态托管并通过同一 WebSocket 通道加入房间；agent 是被控端进程，同样经 WebSocket 接入 server 完成时钟偏移采样并等待绝对执行时刻后模拟空格键触发播放。
- 三方通过 docs/protocol.md 定义的版本化 JSON 文本协议通信，server/server/protocol.py 与 agent/agent/protocol.py 维护等价的消息常量副本，保证跨语言一致性。
- 运行时依赖关系单向：controller 与 agent 均只依赖 server 暴露的 WebSocket API，彼此互不直接通信，可独立部署与重启。
- 编排入口为根目录 docker-compose.yml，仅将 server 容器化并以 scriptcue-data 卷持久化数据，controller 与 agent 通过浏览器或本地进程消费该服务。

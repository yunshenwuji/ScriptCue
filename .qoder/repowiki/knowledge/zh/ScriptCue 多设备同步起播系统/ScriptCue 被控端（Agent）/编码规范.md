- 所有跨进程/跨平台消息类型统一以字符串常量形式声明在 `protocol.py`，并由引擎、GUI、CLI 共同引用，避免硬编码散落的魔法字符串。
- 引擎对外控制方法（`set_ready`、`set_compensation`、`disconnect`）设计为可从任意线程调用，内部通过 `_send_threadsafe` + `asyncio.run_coroutine_threadsafe` 安全写入事件循环。
- 引擎状态变化通过统一的 `on_event(event_dict)` 回调上报，GUI 与 CLI 各自实现不同的事件处理器，保持引擎与表现层解耦。
- 平台相关实现采用运行时分支（`sys.platform == 'win32'` / `'darwin'`）在模块加载时选择底层函数，而非在每次调用时判断。
- 高精度等待统一通过 `scheduler.precise_wait_until(deadline_ms, cancel_event)` 完成，调用方传入 `threading.Event` 以实现可取消的精确等待。
- GUI 与引擎之间通过 `queue.Queue` 传递事件，主线程用 `root.after(POLL_MS, ...)` 轮询消费，避免阻塞 tkinter 事件循环。

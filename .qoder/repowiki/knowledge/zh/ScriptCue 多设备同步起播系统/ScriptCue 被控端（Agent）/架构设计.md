模块以 `agent/` 为 Python 包，提供 GUI 与 CLI 两种入口：`__main__.py` 和 `scriptcue_agent.py` 均启动 `gui.main()`；`cli.py` 提供命令行调试入口。核心逻辑集中在 `engine.AgentEngine`，它维护 WebSocket 连接生命周期、心跳、时钟同步与指令调度，并通过 `on_event` 回调将事件上报给 UI 层。

- 通信协议常量集中定义于 `protocol.py`，被引擎、GUI、CLI 共同引用，保证与服务器端一致。
- 时钟同步由 `clocksync.ClockSync` 实现类 NTP 算法，采集样本并按 RTT 最小选取偏移，支持老化窗口与质量分级。
- 高精度定时由 `scheduler.precise_wait_until` 实现“粗睡眠 + 末段自旋”策略，在 Windows 下调用 `timeBeginPeriod(1)` 提升定时器分辨率。
- 按键注入由 `keysender.KeySender` 抽象，Windows 走 ctypes SendInput，macOS 走 pynput CGEventPost，并提供辅助功能权限检测与引导。
- GUI 层 `gui.GuiApp` 使用 tkinter 构建界面，将引擎运行在独立线程中，通过 `queue.Queue` 轮询引擎事件并更新 UI；配置持久化到用户目录 JSON 文件。
- 依赖方向单向：GUI/CLI → Engine → (ClockSync, Scheduler, KeySender, Protocol)，Engine 不反向依赖 UI。
